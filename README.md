# 📊 Churn DataOps Pipeline

Proyecto completo de DataOps para análisis de churn usando Python, SQL Server y Power BI.

---

## 🚀 Objetivo
Construir un pipeline de datos para:
- Limpieza de datos
- Carga en SQL Server
- Análisis con SQL (KPIs)
- Modelo predictivo de churn
- Visualización en Power BI

---

## 🧰 Tecnologías
- Python (pandas, sklearn)
- SQL Server
- SQL (T-SQL)
- Power BI

---

## 🔄 Flujo del proyecto
1. Limpieza de datos en Python
2. Exportación de dataset limpio
3. Carga en SQL Server
4. Creación de KPIs en SQL
5. Modelo de predicción de churn
6. Visualización en Power BI

---

## 📊 KPIs
- Churn rate
- Ingresos perdidos
- Tenure promedio
- Churn por contrato
- Clientes en riesgo

---

## 🤖 Modelo ML
Modelo de clasificación para predecir clientes en riesgo de cancelación.

---

## 📈 Dashboard
Visualización en Power BI con métricas clave del negocio.

---
